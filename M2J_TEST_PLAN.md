# Milestone 2J — Private Search acceptance

1. Sign into `dev-search.html` with fictional Account A.
2. Search for a saved fictional project or task (for example `Test Grocery Budget`), confirm title and correct area.
3. Try area filter (Finances then Home), verify results change.
4. Refresh, search again, confirm records still display.
5. Incognito sign-in with Account B: confirm Account A records never appear.
6. Return to Account A and confirm its data is still present.

Limits: read-only; first 250 organization records and up to 150 course fixtures; no outside integrations, no cross-account search.
