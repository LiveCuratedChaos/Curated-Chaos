# Milestone 3B — Widget customization

1. Start this folder on port 5212 using your existing private `.env.local`. Sign in to Test Account A.
2. Open The Curation (`/dev-workspace.html?page=curation`) and choose **Customize dashboard**.
3. Add a Tasks widget, set its title to **My Focus**, set **Items to show** to 2, and optionally filter it to Work. Save layout.
4. Refresh, verify the custom title and item count remain. Use duplicate, hide/show, half/full width, and Up/Down or drag to reorder. Save and refresh.
5. Switch to Phone layout, make a different change, save, and verify Desktop layout remains unchanged.
6. In an Incognito window, sign in as Test Account B. Verify Account A's widget layout does not appear. Then return to Account A and confirm its layout still exists.

Use fictional data only. These layout controls affect The Curation; arbitrary widgets on every page, true resize handles, and new connected sources are later work.
