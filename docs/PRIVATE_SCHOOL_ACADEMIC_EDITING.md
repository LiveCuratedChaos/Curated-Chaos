# Reviewed existing academic content

The independent default-off `--allow-private-school-academic-reviewed` scope requires reviewed academic identities and School editing/reading. The owner launcher remains unchanged. This workflow edits existing assessment titles/types/statuses and existing checklist-step titles/completion. It does not add, remove or reorder items, move study sessions, change program/course metadata or copy tasks.

A clean course editor opens a protected outline. Legacy records receive an actionable identity prerequisite and can return to prepare identities through separate approval. Opaque assessment/step handles bind to existing stable academic IDs and a short-lived viewId. Reopening the outline invalidates older handles. Progressive assessment selection retains the whole draft; only an explicit review and approval can save.

The server requires the complete original outline topology and token inventory. It clones the complete source and changes only the allowed academic fields. Unknown extensions, IDs, association, notes, course ordering and study sessions stay exact. Full ownership/source/version/microsecond/payload preflights, an optimistic update, exact version+1 acknowledgement and a fresh reread reuse the existing one-use review engine. Metadata, identity and academic approvals replace one another. Lost acknowledgements never retry.

Reviews show exact Before/After values. Back to academic draft preserves edits for revision; leaving a dirty academic draft explicitly says Discard academic draft and return. Returning after a review cancels its approval and obtains a fresh metadata edit context. Pending and uncertain saves retain protected drafts and cannot be bypassed by refresh, offline, reset or duplicate approvals. Empty outlines do not become invented records or writes.
