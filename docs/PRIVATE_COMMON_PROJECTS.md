# Canonical programs and projects

This integration within the existing private Projects panel provides read-only discovery and explicit original-record editing under existing separately enabled editing scopes. It reuses the saved project, degree and course record identities. It does not create shadow projects, copy live titles or infer a manual project status from academic completion. Existing project management remains available separately.

## Scope and acceptance

The combined browser requires both existing private-project and saved-School read scopes. Opening it explicitly requests sparse owned/private active source metadata. Title, kind and area filters and fifty-item pages show full matching counts. Duplicate titles remain separate records. Source identifiers stay server-side; selected read capabilities are separate from editing, task-link, hierarchy and recovery authority.

Only an explicit selection fetches the selected body. The server must revalidate the source's ownership, identity, version and source metadata, and reject stale, replaced, expired or revoked capabilities. Errors do not become empty results. Closing, offline, sign-out and late replies clear protected views. No provider refresh, writes or schema changes are part of this workflow.
