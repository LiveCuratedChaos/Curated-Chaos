# Offline workspace relationship acceptance

This follows the consolidation and inventory preflight. `server/workspace-convergence-relationships.mjs` is an unmounted, offline check: it accepts an explicitly complete inventory of at most 2,000 active owner-private project/task/link rows. No filesystem, transport, database, provider, credential or configuration access is introduced.

The check reuses the existing manual workspace normalizer and reviewed hierarchy/membership validators. It verifies each engine's current relationship rules independently without relabeling records, manufacturing links, flattening several-parent hierarchy or mapping several project memberships into one `project_id`. Unknown provenance, cross-engine references, missing/wrong-type endpoints, duplicate pairs, unsupported link fields, self-links and cycles fail closed. Archived project links remain included. The existing iterative graph validator handles long hierarchies without recursive traversal.

The result contains counts and constant required-contract descriptions only: no record IDs, titles, task details, relationship targets or payloads. Input rows are never modified. Failure messages are constant and contain no input. Multiple-parent and multiple-project counts describe preservation requirements; they do not propose removing relationships. Reviewed link schemas deliberately reject extensions rather than silently dropping them; the earlier inventory continues to flag other extension compatibility needs.

This certifies relationships only. `migrationReady`, `automaticConversionAllowed`, `fullPayloadCompatibilityValidated` and `historyCompatibilityValidated` remain false; `recordWrites` is zero. Unassigned reviewed tasks with no projects have no relationship domain to validate. Full reviewed task payload validity, payload/status/extension mapping, historical/deleted records, recurrence successor history, version/receipt identity, atomic migration preview/rollback and ordinary autosave remain separate work. No SQL draft is applied or route activated. This is not a migration executor, hosted acceptance, production readiness, persistent offline editing or physical-device evidence.

Synthetic regression coverage includes a combined archived diamond graph with multiple task memberships and manual Waiting-state assignment; empty/unassigned workspaces; dangling, wrong-type and cross-provenance references; duplicate pairs; cycles/self-links; unexpected link extensions; incomplete, foreign, deleted and unknown-provenance inventories; non-disclosing output/errors; source immutability; and a 900-project/899-link chain. Browser code is unchanged, so this batch adds no new UI journey. Targeted inventory/relationship tests passed 10/10. The full Mac offline suite passed 2,061/2,061, zero failures/cancellations/skips or platform exclusions; privacy, whitespace and launcher checks passed. No new browser run is claimed for this unmounted module. The preceding PR18 source had successful GitHub browser/native/offline/concurrency CI; the additional local full browser run passed 98 cases and timed out on six, all six passing on a focused rerun. That is not a clean single local full run.

The owner's two existing checkouts and running app remain unchanged. Apple Calendar refresh stays off. Publication, database acceptance, migration and deployment retain their applicable approval gates.
