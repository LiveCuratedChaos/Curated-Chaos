# Saved School title search

This integration extends universal title discovery under the existing saved-School-read and title-search scopes. Explicit School searches and authorized global all-type title queries reuse the canonical saved program/course records. Task, Notes and Calendar pages retain their existing type-specific workflows. Ordinary title search remains literal; existing interpreted “school tasks” continues to mean tasks in the School area.

Results contain only title, record kind, School section and a separate opaque selected-read capability. Notes, assessments, steps and study sessions are not fetched before selection. School results never receive project/task/recovery/edit capabilities. Selecting details uses a separate School reader context; it does not replace the main School viewer's capabilities. Search read tokens cannot open the metadata editor.

Every source is bounded to2000 records. Enabling the School search source explicitly allows a6000-record combined inventory and fifty-row pages; the old combined2000 bound remains when School search is disabled. Duplicate canonical IDs across any source fail verification. No source is truncated into misleading counts. School-only filters require all/School area and no task status, priority or dates. Other explicit types avoid School source reads.

Reusable School shortcuts retain these exact filters. A shortcut whose School scope is unavailable cannot run or silently become a broader search. Existing shortcuts remain compatible. Source errors, expiry, malformed/future/foreign/shared/deleted records and late sign-out/search replies fail closed. Details remain read-only and preserve exact literal text and leading newlines.

## Course and program filters

The record type selector supports all School titles, just programs, or just courses. “Find courses about leadership” and “School programs” preview the same filters. The protected search checks the full authorized School inventory, filters by kind before counting or paging, and issues read handles only for displayed originals. A shortcut saves its type and title query. It can be restored with the encrypted workspace and needs current School access to run.
